# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/SaifUllahUmar0317/my_portfolio.git
```

Go to project folder

```bash
cd my_portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```

---

# 🏗 Build for Production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
